Ejemplo: mapa incrustado como iframe

Este archivo es solo un ejemplo de uso. El truco es el <div> contenedor con padding-bottom en porcentaje: eso reserva la altura según el ancho disponible, para que el iframe sea responsive dentro de cualquier sitio (sin depender de un alto fijo en píxeles que se vea mal en celular).

Código para copiar en cualquier otro sitio (cambia TU-DOMINIO por donde publiques el mapa, ej. tu URL de GitHub Pages o Render): 

<div style="position:relative;width:100%;padding-bottom:75%;">
  <iframe
    src="https://TU-DOMINIO/index.html?embed=1"
    style="position:absolute;top:0;left:0;width:100%;height:100%;border:0;"
    loading="lazy"
    referrerpolicy="no-referrer-when-downgrade"
    title="Mapa de emergencia · Sismo Chocó">
  </iframe>
</div>
